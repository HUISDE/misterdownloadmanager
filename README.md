# pr-shots

Screenshots for pull request descriptions, one folder per PR (`<pr number>/<name>.png`). Pull
requests embed them from
`https://raw.githubusercontent.com/anefzaoui/misterdownloadmanager/pr-shots/<pr>/<name>.png`.

This branch holds images only and is never merged. Test data in shots uses neutral folders
(no personal paths), never IDM artwork, never copyrighted media beyond a page title.
